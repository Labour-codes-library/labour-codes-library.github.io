Can contract labour be used in core activities?

  • Employing contract labour in core activities is prohibited, except in the cases the Code lists s. 57(1).
  • A core activity is any activity the establishment is set up for, and anything essential to it s. 2(1)(p).
  • Unless the establishment is set up for them, sanitation, watch and ward, canteen, loading and unloading, housekeeping and similar work are not core s. 2(1)(p).
  • It is allowed if the work is ordinarily done through contractors, does not need full-time workers for most of the day, or is a sudden increase in work to be finished in a specified time s. 57(1), proviso.
