Calculators

Each calculator shows its working step by step, and every step links to the provision it applies. Figures come only from the official text.

Gratuity

15 days' wages for each year counted (SS Code s.53).

What counts as wages (50% rule)

Adds back excluded allowances above one-half of pay (CW Code s.2(y)).

Overtime pay

Twice the rate of wages, with part hours rounded (OSH Code s.27, OSH Rules r.69).

Maternity benefit

Average daily wage for up to 26 weeks, plus medical bonus (SS Code ss.60, 64).

Retrenchment compensation

15 days' average pay per year, and notice pay (IR Code s.70).

Bonus

8⅓% to 20% of wages, with the notified ₹21,000 and ₹7,000 ceilings (CW Code s.26).
