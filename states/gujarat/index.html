Code on Social Security Final rules

The Code on Social Security (Gujarat) Rules, 2023

  • No. GR/2023/158/PGA/172021/24659/M3
  • Notified 30 Dec 2023
  • English
  • scanned copy, text read by machine

Read the rules in full

Official copy, 2.6 MB · our copy

Amended by The Code on Social Security (Gujarat) (Amendment) Rules, 2026, No. GR/2026/14/PGA/172021/24659/M3, 28 Jan 2026, Gujarat Government Gazette Extraordinary, Part IV-A, No. 18, 13 February 2026; in force 13 Feb 2026: official copy · our copy

It changes the fixed-term proviso in rule 7(a) (“Five years” to “One year”), substitutes rule 14 on funeral expenses (a deposit of fifteen thousand rupees, or any higher amount the Central Government prescribes, within forty-eight hours), inserts rule 14A, substitutes rule 70, changes “four months” to “three months” in rule 79(1), adds rule 89A and substitutes Form IV.

Also: The Commissionerate’s scan of the amendment, which carries highlighter marks: official copy · our copy

The 2023 rules are not out of date: they are still the principal rules, and rule 1(3) brings them into force on the commencement of the Code. Read them with the 2026 amendment.

How this was checked

The Commissionerate page links each row to the right file, but the sizes it prints are on the wrong rows and the file names do not name the rules, so the files were identified from their first pages. Its “Notification” row is Gazette Extraordinary Nos. 44-50 of 29 May 2026, notifications under the Code, not rules. The Code on Wages file has a text layer made by scanning software (Adobe Scan), not reliable word for word, so it is not used as text.
